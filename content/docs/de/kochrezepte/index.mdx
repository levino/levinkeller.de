## So sind die Rezepte aufgeschrieben

Die Rezepte stehen als Tabelle im Format von
[Cooking for Engineers](https://www.cookingforengineers.com/): Links stehen die
Zutaten, rechts davon die Arbeitsschritte. Ein Schritt überspannt genau die
Zutaten, die er zusammenführt – man liest die Tabelle von links nach rechts und
sieht auf einen Blick, was wann in welche Schüssel kommt.
